Tip

For your own repos, run git pull first. This malware gets into GitHub, not your laptop, so your local copy can look clean while GitHub has the infected version.

#2. Read the result

If something is wrong you get a list. Each line has a level, a file and a message:

LevelMeaningWhat to do
HIGHDangerous. It can run by itself and steal from you.Do not install, run or open the project. Clean it first.
MEDWorth a look. It does not run by itself.Read it and decide. Most can be fixed with forkguard fix.

#4. Fix it on GitHub too

forkguard fix cleans your computer. forkguard pr cleans GitHub as well, by opening a pull request with the fix:

Commit or stash your own changes first. Details in `forkguard pr`.

#5. Turn on automatic protection

Close the terminal and open a new one. From now on forkguard checks a project before npm install, npm run dev and friends, and after git clone. When everything is clean you see nothing at all.

#Cheat sheet

I want to…Run
Check this folderforkguard
Check another folderforkguard path/to/project
Check a GitHub repo without cloning itforkguard owner/repo
Check all my repos on GitHubforkguard --mine
Clean this folderforkguard fix
Clean it on GitHub with a pull requestforkguard pr
Send the fix to the repo I forked fromforkguard pr --upstream
Check automatically before npm and after gitforkguard setup
Turn automatic checks offforkguard setup --remove
Skip the check onceFORKGUARD_SKIP=1 npm install
Get results as JSONforkguard --json
Add safety rules for AI agents (next release)forkguard agent --write
See the versionforkguard --version
