#Name

forkguard --mine checks every repository you own on GitHub, every branch, using the same safe method as `forkguard owner/repo`.

forkguard --mine - check all repositories you own

#Synopsis

#Description

This is the fastest way to know whether your whole GitHub is clean. Run it once now, and again whenever you hear about a new attack. It lists your repos, then checks four at a time. About 50 repos takes a minute or two.

It checks repos you own, including forks and archived repos. Repos in organizations where you are only a member or collaborator are not included.

#You need to be logged in

Either log in with the GitHub CLI:

or set a GITHUB_TOKEN (or GH_TOKEN) environment variable with a personal access token. Without either you get: “Log in first so forkguard can list your repos”.

Lists repositories with affiliation=owner via gh or the GitHub API, then runs the remote check on each, four at a time.

Requires gh auth login, or GITHUB_TOKEN / GH_TOKEN.

#Output

Then you get the full details for every repo that is not clean.

#Options

--json
Print a list of repo results, one per repo, instead of text. See JSON output.

#Exit status

CodeMeaning
0Clean, or only MED findings.
1Something HIGH was found.
2forkguard itself could not run, for example when you are not logged in.

The same codes work in scripts and CI. See Exit codes.
