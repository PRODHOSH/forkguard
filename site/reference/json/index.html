#A folder

#A GitHub repo

If the repo could not be downloaded you get { name, url, error } instead, and the exit code is 2.

#All your repos

forkguard --mine --json prints a list of the repo results above, one per repo, sorted by name. Each also has an archived field.

#Fields

FieldMeaning
level"high" or "medium".
fileThe file, relative to the project. A few findings use a label such as (latest commit) or a path to npm itself.
ruleWhich check found it. See the list below.
messageWhat is wrong, in plain words.
fixWhat forkguard fix will do, or null if a person has to decide.
checkedHow many files were looked at.
rootThe folder that was checked, resolved to a real path.

#Rule ids

Each id is explained in What it catches.

#Fix values

fixWhat fix does
deleteDeletes the file.
delete-dirDeletes the folder.
stripCuts the malware out of your file.
scriptRemoves the injected step from a package.json script.
autorunRemoves the folder-open task from .vscode/tasks.json.
settingTurns automatic tasks off in .vscode/settings.json.
gitignoreRemoves the malware’s line from .gitignore.
ignore-envAdds .env* rules to .gitignore.
untrackRemoves a committed .env from git, keeping it on disk. Only forkguard pr does this.
nullA person has to decide.
