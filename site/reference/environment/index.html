VariableWhat it does
FORKGUARD_SKIP=1Skips the automatic check for one command. Only read by the shell hooks.
GITHUB_TOKEN, GH_TOKENUsed to talk to GitHub when the GitHub CLI is not available. Needed by --mine, and by pr for opening the pull request.
NO_COLOR=1Turns off colors in the output.

#A token for GitHub

The GitHub CLI is tried first (gh auth token). If it is not installed or not logged in, GITHUB_TOKEN and then GH_TOKEN are used. A token needs permission to read your repos for --mine, and to push and open pull requests for pr.

Warning

Never paste a token into a command that is saved in your history, and never commit one. forkguard reads it from the environment and sends it only to api.github.com.
