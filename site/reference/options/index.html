OptionWorks withWhat it does
--jsonchecking a folder, a link, or --minePrint the results as JSON instead of text. See JSON output.
--mineon its ownCheck every repo you own on GitHub. See `forkguard --mine`.
--upstreamprSend the pull request to the repo you forked from. See `forkguard pr`.
--removesetupTake the automatic checks back out of your shell profile.
--writeagentAdd the agent rules to AGENTS.md, CLAUDE.md and similar files instead of printing them. Next release.
--version, -vanythingPrint the version.
--help, -hanythingPrint all commands.

#Commands

CommandArgument
forkguard [folder]A folder to check. Defaults to the current folder.
forkguard <owner/repo or url>A GitHub repo or any git URL to check.
forkguard fix [folder]A folder to clean.
forkguard pr [folder]A git repo to clean and open a pull request on.
forkguard setupNo argument.
forkguard agent [folder]A folder whose agent files to write. Defaults to the current folder.

#Internal

forkguard --gate <tool> <args…> is what the shell hooks call. It exists for forkguard setup, and is not meant to be typed by hand. It exits 1 to stop a package manager and 0 otherwise.

Note

fix, pr, setup and agent are commands, not flags. They go first: forkguard fix ./app, not forkguard ./app fix.
