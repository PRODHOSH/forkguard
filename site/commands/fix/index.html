forkguard fix

Remove what forkguard found, on your computer, and get your original files back.

#Name

forkguard fix removes the malware forkguard found in a folder, and restores your original files from git history where it can. Nothing is pushed anywhere.

forkguard fix - remove detected malware from a folder

#Synopsis

#Description

Runs a check, then applies the fix for every problem that has one. Cutting off the hidden code is the easy part. The malware also adds fake require lines to the top of files and sometimes mangles line breaks, so fix handles all of it and then checks again.

ProblemWhat fix does
Hidden init fileDeletes it
Fake fontDeletes it
Decoy fonts folderDeletes the whole folder
Dropped .bat or .orc files, history-rewriting scriptsDeletes them
Hidden code in one of your filesCuts out only the hidden part and keeps your code
Env-variable loader blockRemoves only that block
Injected require linesRemoves only those lines
node init && or a font file run in a scriptRemoves only that step from dev, build and start
VS Code auto-run taskRemoves only that task and keeps your other tasks
VS Code automatic tasks settingTurns it off
config.bat in .gitignoreRemoves that line
.env not ignoredAdds .env* rules to .gitignore

#Restoring your originals

After cleaning a file, forkguard looks back through git history for the last clean version of it. If that version has the same code (ignoring spacing), it puts back your exact original, so even line breaks the malware mangled come back.

#What it does not fix by itself

  • A known bad npm package, a risky install script, an already installed bad package, and an infected npm. These need a person to decide, and forkguard tells you what to do.
  • A file that matches a known signature but has nothing it can safely cut. It is left as is and reported again as “Still needs a look”.
  • Committed .env files stay on disk and in git. `forkguard pr` takes them out of git for you.

Warning

Not a git repo? There is no history to undo from, so forkguard asks “Continue? (y/N)” before changing anything.

Applies fixes: delete, delete-dir, strip (hidden tail, loader, prelude), script, autorun, setting, gitignore, ignore-env. Restores the original bytes from history when the cleaned code equals a clean historical version modulo whitespace.

Does not fix: bad packages, lifecycle scripts, installed packages, infected npm, committed .env (use pr).

#Output

WordWhat happened
deletedThe file was nothing but malware, so it is gone.
cleanedThe file is yours. Only the bad part was removed.
restored your original from git historyforkguard found the clean version you wrote before the attack and put it back exactly.
removed the auto-run task, turned automatic tasks offA VS Code task or setting was changed.

If something is left, you get “Still needs a look” with the remaining findings.
